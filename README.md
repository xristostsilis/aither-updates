# Aither — ενημερώσεις

Από εδώ το Aither (αυτοματισμός ραδιοφωνικού σταθμού για macOS) κατεβάζει μόνο του τις νέες εκδόσεις.

**Νέα εγκατάσταση:** κατεβάστε το [Aither.dmg](https://github.com/xristostsilis/aither-updates/releases/latest/download/Aither.dmg), ανοίξτε το και σύρετε το Aither στις Εφαρμογές. Την πρώτη φορά: δεξί κλικ → Άνοιγμα.
Απαιτεί Mac με Apple Silicon (M1 ή νεότερο) και macOS 14 ή νεότερο.

Κάθε ενημέρωση είναι ψηφιακά υπογεγραμμένη (EdDSA)· το Aither δεν δέχεται πακέτα χωρίς σωστή υπογραφή.
